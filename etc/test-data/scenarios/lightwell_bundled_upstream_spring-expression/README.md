# lightwell_bundled_upstream_spring-expression — N upstream IDs collapse to one verdict, losslessly

Snapshot: `lightwell-osv` @ `ae0cbae` (2026-11-13, 288 advisories). Rule: `--rule scoped`.
Encodes `docs/README.md` §3 (last paragraph).

A Lightwell record is one *remediated build*, not one vulnerability. One record can fix many
upstream vulnerabilities at once, and it then carries all of their identifiers in `upstream[]`.
`upstream` is the fixed upstream — it is **not** `aliases` and **not** `related`, so the record
keeps its own `RHLW-…` identity rather than being folded into a CVE.

The consequence for a consumer: **one advisory, one verdict — not 14.** All 14 identifiers must
survive on that single verdict.
