# lightwell_pep440_local_version_pypdf2 — PEP 440 local versions sort above their base

Snapshot: `lightwell-osv` @ `ae0cbae` (2026-11-13, 288 advisories). Rule: `--rule scoped`.
Encodes `docs/README.md` §3 (ecosystem table).

The 18 `Red Hat Lightwell:PyPI` records in the snapshot mark their remediated build with a PEP 440
**local version** segment, `+rhlw.N`. PEP 440 orders a local version *above* the public release it
annotates, so `3.0.1 < 3.0.1+rhlw.1`, and the exclusive `fixed` bound therefore excludes the
remediated build while still including its base. A comparator that dropped or mis-ranked the local
segment would either treat the remediated build as vulnerable or treat the base as fixed.

`check_ranges.py` uses `packaging.version.Version` (`pypi_cmp`) for these; Maven ordering is not
applied to PyPI records.
